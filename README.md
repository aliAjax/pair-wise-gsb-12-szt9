# 车辆调度小工具

本地优先（Local-first）的车辆调度前端：车辆清单、派车登记、占用台账。

- 行业：物流
- 技术栈：Vue3、Vite、TypeScript、Pinia、Naive UI
- 启动：`npm install && npm run dev`
- 构建：`npm run build`
- 逻辑自测：`npm run selftest`（迁移补齐/回滚、合并冲突、司机重复分配、离线合并）

## 本地优先流程

- **派车登记**：选择车辆/司机/占用时段登记任务。同一车辆重叠时段只允许一个有效任务，同一司机不能重复分配；有未解决冲突的车辆暂停派车。
- **任务版本**：每条任务带 Lamport 版本（站点 ID 决胜）。多端同时提交时保留先确认的一版，其余进入冲突区，可人工改留。
- **断网续登**：离线时登记与状态变更进入待同步队列；网络恢复（或点“立即同步”）后与模拟服务端台账合并（LWW + 冲突检测），合并结果回写远端收敛。
- **冲突区**：未解决冲突标记在车辆卡片并暂停该车派车；解决后自动恢复。
- **占用台账**：任务的投影视图，含占用时段、任务版本、状态与来源（本地/对端/迁移）。
- **数据迁移**：旧数据缺少任务版本或占用时段时先补齐（版本按创建时间、时段按默认 4 小时）再参与判断；迁移前自动快照，迁移中断保留原记录并从快照恢复。
